# 标签管理UI设计文档

## 设计概述

标签系统是博客内容的分类神经系统。本设计延续网站整体的**拟物手绘风格**与**新丑风排版**，将标签设计为具有实体感的彩色贴纸/印章，强调可触感与即时识别性。标签不仅是分类工具，更是页面的视觉点缀元素。

## 视觉风格

## UI 场景设计

### 场景一：文章卡片上的标签（前台展示）

**位置**：文章卡片标题上方，横向排列
**布局**：flex-wrap，gap: 8px，最多展示3个标签，超出显示「+N」
**样式**：
- 未hover状态：inactive样式（透明底色+纯色文字+黑色边框）
- hover状态：标签整体上浮1px，阴影加深，保持inactive样式（不切换为active）
- 点击行为：跳转至该标签的筛选结果页 `/tag/:tagName`

**视觉示例**：
```
┌─────────────────────────────────┐
│ ┌─────┐ ┌─────┐                 │
│ │生活 │ │读书 │  ← 琥珀黄/绿色胶囊 │
│ └─────┘ └─────┘   黑色边框 2px    │
│                                   │
│  关于慢生活的思考                  │
│  在这个快节奏的世界里...          │
└─────────────────────────────────┘
```

### 场景二：文章详情页标签（BlogPost）

**位置**：标题下方，作者信息上方
**布局**：横向排列，gap: 10px
**样式**：
- 比卡片标签稍大（Height: 32px, Padding: 0 18px, Font: 13px）
- 增加一个「文章类型标签」（如「博文」蓝色背景），放在最左侧作为锚点
- 类型标签与内容标签之间用竖线分隔符 `|` 或 8px 间距区分
- 内容标签hover效果同卡片标签

**视觉示例**：
```
┌────────┐ ┌──────┐ ┌──────┐
│ 博文   │ │ 生活 │ │ 读书 │
└────────┘ └──────┘ └──────┘
 蓝色填充   琥珀黄    绿色
 白色文字   透明底    透明底
```

### 场景三：标签筛选器（Blog / Journal / Thoughts 列表页）

**位置**：搜索栏下方，文章列表上方
**布局**：居中对齐，flex-wrap，gap: 10px
**组件组成**：

1. **「全部」按钮**：
   - 样式：灰色系 `#6B7280`，圆角胶囊，黑色边框
   - 未选中：bg-gray-100 + 灰色文字
   - 选中：bg-gray-800 + 白色文字 + 粗阴影
   - 图标：左侧带一个小的 `⊕` 或 `∞` 符号

2. **内容标签按钮**：
   - 未选中：inactive样式（底色为该颜色15%透明度，文字为该颜色，黑色边框，无阴影）
   - 选中：active样式（纯色填充，白色文字，黑色边框，2px阴影）
   - hover（未选中）：底色加深至25%透明度，阴影出现
   - 每个标签右侧可显示小徽章数字（该标签下文章数量），Font: 10px，圆角小方块

3. **「+ 管理」按钮**（仅管理员可见）：
   - 右侧浮动，样式为虚线边框胶囊
   - 点击跳转 `/admin` 的标签Tab

**交互细节**：
- 支持多选（按住可复选多个标签，取交集过滤）或单选（点击切换）—— 建议先实现单选
- 选中后立即过滤列表，无需确认按钮
- 切换标签时列表区域显示轻微 loading shimmer 或淡出淡入动画
- 空状态：当某标签下无文章时，标签按钮置灰（opacity: 0.4），hover 显示 Tooltip「暂无内容」

**视觉示例（选中状态）**：
```
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ 全部 │ │ 生活 │ │读书 3│ │ 旅行 │
└──────┘ └──────┘ └──────┘ └──────┘
 灰色填充  琥珀黄    绿色      透明
 白色文字  填充底   填充底    透明底
          白字    白字+徽章
```

### 场景四：后台标签管理Tab（Admin）

#### 4.1 页面头部统计卡片

在标签列表上方，横向排列 3 张统计卡片：

| 卡片 | 内容 | 样式 |
|------|------|------|
| 总标签数 | 数字 + 小标签图标 | 白色底，黑色边框，黄色左上角贴纸条 |
| 使用最多 | 标签名 + 文章数 | 白色底，黑色边框，蓝色左上角贴纸条 |
| 本月新增 | 数字 + 趋势箭头 | 白色底，黑色边框，粉色左上角贴纸条 |

卡片样式统一：
- 圆角：16px
- 边框：2px solid black
- 阴影：4px 4px 0px black
- 贴纸条：宽 80px，高 24px，旋转 -2deg，压在卡片左上角

#### 4.2 标签列表表格

**表格结构**：
| 列 | 宽度 | 内容 |
|----|------|------|
| 颜色 | 48px | 圆形色块，24px直径，黑色边框 |
| 名称 | flex-1 | 标签名称文字，可编辑 |
| Slug | 120px | 标签标识（可选展示） |
| 文章数 | 80px | 数字，加粗，右侧小圆点 |
| 创建时间 | 120px | YYYY-MM-DD，灰色小号字体 |
| 操作 | 100px | 编辑 + 删除图标 |

**行样式**：
- 常规行：白色背景，hover 时 bg-gray-50，微上浮
- 编辑行：行内切换为输入框+color picker，输入框黑色边框，圆角8px
- 行与行之间无分割线，用间距 8px 区分（更拟物，像贴纸堆叠）

**操作按钮**：
- 编辑：铅笔图标，hover 变蓝色，背景变蓝50
- 删除：垃圾桶图标，hover 变红色，背景变红50
- 删除需二次确认：Tooltip 或 小弹窗「删除后 X 篇文章将移除此标签」

#### 4.3 新建标签表单

**触发器**：黄色按钮「+ 新建标签」，neo-border + neo-shadow
**表单区域**：
- 名称输入框：黑色边框，圆角12px，placeholder「输入标签名称...」
- 颜色选择器：一排 8 个圆形色块按钮（候选色），选中的色块有黑色边框+白色对勾
  - 每个色块 36px 直径，间距 8px
  - 色块本身带 2px 黑色边框，hover 放大 1.1 倍
- 自定义颜色：input type="color"，但更改为圆形触发按钮，点击展开原生 picker
- 提交按钮：蓝色填充「创建标签」，黑色边框，黄色hover态

### 场景五：独立标签索引页 `/tags`

**页面结构**：

1. **Hero区域**：
   - 标题：「标签索引」大号手写字体（Caveat），旋转 -2deg
   - 副标题：「按主题探索所有内容」
   - 背景：浅黄色 `#FEF9C3`，右下角放一个半透明的标签贴纸装饰

2. **标签云区域**：
   - 所有标签以不同尺寸展示（根据文章数量）
   - 文章数越多，标签越大（Font-size: 12px → 20px，Padding 自适应）
   - 布局：flex-wrap + justify-center，gap: 12px
   - 每个标签都是可点击的胶囊按钮
   - 未选中：inactive样式
   - hover：上浮 + 阴影加深
   - 点击后下方加载该标签的文章

3. **文章列表区域**：
   - 点击标签后，下方以动画形式展开文章列表（高度从0展开，duration: 400ms）
   - 列表标题：「「生活」标签下的 5 篇文章」
   - 文章卡片样式同 Blog 列表页卡片
   - 混合展示所有类型（博文/日志/随想），以类型徽章区分
   - 空状态：黄色便签样式卡片「这个标签下还没有内容哦～」

## 交互规范

### 标签按钮状态机

```
[默认态] ──hover──▶ [Hover态] ──click──▶ [激活态]
    │                                    │
    │                                    │
    └──────────────click───────────────┘  (取消激活)
```

状态样式对照：

| 状态 | 背景 | 文字 | 边框 | 阴影 | 位置 |
|------|------|------|------|------|------|
| 默认 | 颜色×15%透明 | 颜色值 | 2px black | none | 原位 |
| Hover | 颜色×25%透明 | 颜色值 | 2px black | 2px 2px 0 black | translate(-1px,-1px) |
| 激活 | 颜色值100% | 白色 | 2px black | 3px 3px 0 black | 原位 |
| 禁用 | 颜色×10%透明 | 灰色 | 2px gray | none | 原位 |

### 动画规范

| 交互 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 标签hover | 上移1px + 阴影加深 | 150ms | ease-out |
| 标签点击(激活) | 瞬间切换样式 + 轻微缩放脉冲(scale 0.95→1) | 100ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 筛选切换 | 列表区域 opacity 0→1 + y 偏移 10px→0 | 300ms | ease-out |
| 新建标签表单展开 | 高度展开 + 轻微回弹 | 400ms | cubic-bezier(0.175, 0.885, 0.32, 1.275) |
| 标签删除 | 行元素 opacity→0 + x 偏移 -20px | 250ms | ease-in |
| 标签索引页文章展开 | 高度从0到auto + stagger 子元素 | 400ms | power3.out |

## 响应式适配

### 移动端 (< 640px)

- 标签筛选器改为横向滑动（overflow-x-auto），不再 wrap
- 标签胶囊缩小：Height 24px，Padding 0 10px，Font 11px
- 文章卡片上的标签最多展示2个
- 后台标签表格改为卡片式列表（每行一个卡片）

### 平板端 (640px - 1024px)

- 标签筛选器正常 wrap
- 后台表格保持表格形式，但操作按钮放大以便触控
